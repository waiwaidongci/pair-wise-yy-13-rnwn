# hxyfront-62012 纺织染整小样 · 补料复核台

小样复染补料的复核工作台，按订单容差管住"补多少、谁补、谁复测"，避免凭经验补过头返工。

## 业务规则

1. **每批只允许一张在途单**：待确认、保温中、待复测、超限待处置均占用在途名额。
2. **容差按订单设定**：三轴 ΔL（明度）、Δa（红绿）、Δb（黄蓝）各有 ± 限值。
3. 登记必填**余液、追加量、保温温度、补料人**，并指定复核人。
4. **余液不足、温度偏离工艺范围、补料人兼复核人**，任一命中即留在**待确认**，须他人确认放行（余液补足或改用量后才可继续）。
5. 保温完成后由**另一人复测**，三轴全部落在订单容差内才算**通过**。
6. 超限只给出**后续建议**（补加方向与参考量），系统**不自动追加**。
7. **改用量使原复测失效**：旧单留档可查，按新用量另开新单，同订单序号顺延。

## 业务文件

- `src/biz/rules.ts` — 规则：类型、登记校验、三轴判定、超限建议（纯函数）
- `src/biz/archive.ts` — 档案：订单容差/批次余液/人员/单据种子数据与状态流转台账
- `src/biz/pages.tsx` — 页面：补料登记、在途工作台、单据台账（按订单筛选、按序号排序）
