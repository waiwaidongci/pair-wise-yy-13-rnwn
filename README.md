# hxyfront-62012 染整小样补料复核台

源提示词编号：7

复染凭经验补染料容易补过头，本台用于补料登记与保温后复测复核：

- **每批一张在途单**：同一小样批次存在「待确认 / 待复测」补料单时，不能再登记新单。
- **按订单容差**：每张订单配置保温温度与允差、最低余液量，以及 ΔL\* / Δa\* / Δb\* 三轴容差。
- **登记**：余液量、各染料追加量、保温温度、补料人；余液不足或温度偏离时留在**待确认**，修正后重新校验。
- **保温后复测**：必须由补料人之外的另一人复核（补料人兼复核人退回待确认）；三轴绝对值均在容差内才**复测通过**。
- **超限不自动追加**：任一轴超差只给出后续校正建议，需要改用量时另开新单。
- **改用量留档**：已复测单据修改追加量后，原复测立即失效，旧单留档并按订单下一序号另开新单。
- 左侧列表按订单分组、组内按序号排列；数据通过 localStorage 持久化。

业务文件拆分：

| 文件 | 职责 |
| --- | --- |
| `src/rules.ts` | 规则：在途单约束、登记校验、容差判定、超限建议、复测复核、改用量留档（纯函数） |
| `src/archive.ts` | 档案：订单容差、批次、补料单存档与 localStorage 持久化、演示数据 |
| `src/Station.tsx` | 页面：补料复核台（登记、待确认修正、复测、超限建议、改用量） |
